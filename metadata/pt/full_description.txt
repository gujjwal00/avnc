AVNC é um cliente VNC de código aberto para Android. Permite controlar remotamente qualquer dispositivo que corre um servidor VNC.

Funcionalidades:

- Desenho Material (com tema Escuro)
- Gestos configuráveis
- Chaves Virtuais
- Suporte de Repetidor VNC
- Suporte Wake-on-LAN
- Túnel SSH embutido (VNC sobre SSH)
- Modo de Imagem-em-Imagem
- Modo só de visualização
- Modo Sem-Vídeo
- Descoberta Automática do Servidor Zeroconf
- Importar/Exportar servidores
- Sincronização da Área de transferência com o servidor
- `vnc://` suporte de URI
- Suporte de TLS (AnonTLS, VeNCrypt)
- Suporte de codificação apertada
